# one haiku about debugging, three lines, in the 5-7-5 syllable shape, at most 200 characters, as plain text

```
I edit line eight
The server runs somewhere else
The sun warms my desk
```

### About the Entry
Captures the quiet horror of a late-night debugging session when the developer discovers they have been modifying a file never being executed by the active server, just as dawn breaks.
